# qa-ai-m6-delivery

Навчальний стенд модуля 6 курсу «AI-інструменти для QA»: сторінка оформлення доставки продуктів.

## Форк

Натисни **Fork** угорі сторінки репозиторію.

У формі форку **зніми галочку «Copy the default branch only»**. Якщо її лишити, у форк потрапить тільки `main`, гілки `feature/promo-code` не буде, і PR не буде з чого відкрити.

## Pages

У своєму форку: **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `feature/promo-code` / `(root)` → Save**.

За хвилину сторінка відкриється за адресою `https://<твій-логін>.github.io/qa-ai-m6-delivery/`.

Гілка саме `feature/promo-code`: `main` — це стан до зміни, а тестуєш ти зміну.

## PR

У своєму форку: **Pull requests → New pull request**. База — твій `main`, compare — `feature/promo-code`.

PR не зливай: він потрібен відкритим, щоб агент читав diff.
