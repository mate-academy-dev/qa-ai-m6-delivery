# Запасний шлях

Ці файли потрібні тільки тоді, коли конектор не підключився і агент не може прочитати джерело сам.

`ticket-context.md` — тікет у зібраному вигляді, замість кроку 1 через Atlassian MCP.

`promo-code.diff` — вивід `git diff main..feature/promo-code`, замість кроку 4 через GitHub MCP.

## Чим це гірше за живий прогін

Файл уже зібраний, тому перевірити заземлення на ньому нема на чому: ти не можеш зіпсувати вхід і подивитись, чи агент це помітить. Саме ця перевірка і є навчальною частиною топіка 1.

Файл статичний. Якщо ти зміниш щось у своєму тікеті або у своїй гілці, він про це не знатиме, і розбіжність між файлом і реальним станом доведеться тримати в голові.

Номер тікета в `ticket-context.md` не твій. У власному звіті став свій ISSUEKEY, інакше трасування веде в чужий тікет.

Прохідність модуля від цього не залежить: усі кроки, крім самого підключення, робляться на цих файлах так само.
